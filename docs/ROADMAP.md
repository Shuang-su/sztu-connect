# 路线

## v0.1：事件可提交、关系可回查

- Event + Time + Claim/Citation
- 人物、组织、地点、制度、主题 Node
- Event 单写关系、Markdown wikilink 与自动 backlink
- 自动生成各 Node 目录索引
- 编年体、纪传体、典制体和专题 Collection
- Codex plugin + 本地 CLI
- 供应商无关知识 JSONL
- 分级隐私扫描

## 下一步

- 从公开、低争议来源建立首批真实 Event
- 增加 Event 重复检测和 Node 别名消歧
- 增加显式 Markdown chunk anchor
- 提供本地全文／向量检索参考实现
- 增加静态只读浏览器

MCP、WebMCP、云端向量库、网页归档和部署在有真实需求与可测试 runtime 后再决定。
