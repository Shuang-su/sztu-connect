## 3. Computer History 与聊天工具衔接

### Computer History

九种客户端共用材料探索流程，Computer History 单独按实际能力判断，不列为全部客户端的必备条件。

- 先检查能力、运行状态及可用历史范围。已有采集配置保持不变；需要恢复时使用官方支持的操作。
- 首次启用通过产品原生设置与用户确认完成，不用修改配置文件冒充启用，也不自动扩大应用或网站采集范围。
- 当前官方入口有 macOS、账号及工作区条件；提示词授权不能替代产品首次同意或管理员授权。[Computer History 官方说明](https://learn.chatgpt.com/docs/customization/computer-history)
- 检索范围采用**全部现有保留历史**：先查可用摘要，再按校园线索读取相关事件片段。分别报告摘要与原始事件的覆盖范围；原始事件通常最多保留 48 小时，摘要可以保留更久，新启用不会补出过去的历史。[历史保留说明](https://learn.chatgpt.com/docs/customization/computer-history#privacy-and-local-storage)
- 历史用于定位网页、文件和消息，再回到原始材料核验。没有历史或功能不可用时如实说明，继续处理已有材料。
- README 不宣称本项目新增了后台采集器、活动流自动导入或完全离线处理能力。

### 已交付的聊天工具

复用现有工具清单，不重新归档、不更换固定版本，也不新增安装包托管。

已有聊天导出直接进入阅读与来源定位，不强制先转换 JSONL；需要结构化整理或本地回看时再使用现有映射、校验与 HTML 功能。没有导出时，根据当前系统和实际版本提供适用工具的下一步，不因进入探索流程就自动打开数据库或导出整个账号。

工具安装尚待授权，不妨碍先阅读已经提供的材料；工具来源校验与聊天内容核验继续分开。
