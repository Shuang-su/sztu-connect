- 在现有 `codex/readme-archive-onboarding` 分支保存用户本轮修改，不切换或改写 `main`。
- 用户最后明确要求不改写现有文案。撤回 Agent 临时添加的句号、中英文空格及“正在接入”表述，恢复用户原文。

- 只读核对关联聊天工具任务的状态；不接管该任务、不增加导出器、归档源码或导入接口。

## 验证

1. 核对当前分支、暂存区、完整 diff 与六个用户文件的内容哈希。
2. 使用已有虚拟环境检查配置 JSON、`doctor`、记录 Schema 与引用、严格隐私扫描。
3. 连续构建两次，比较全部生成文件的 SHA-256，并运行严格综合检查与完整单元测试。
4. 检查 Markdown diff 与既有 README 名称、标题和链接测试；不将测试通过解释为文档语义全部正确。
5. 将本轮请求、实际操作、验证结果和未解决差异纳入变更记录。提交说明标记为文档 checkpoint，而非新增运行能力或发布验收。
6. 精确暂存本轮文件并创建本地提交，核验提交内容、用户文件哈希与剩余工作区状态；不 push、不创建 PR、不合并。
