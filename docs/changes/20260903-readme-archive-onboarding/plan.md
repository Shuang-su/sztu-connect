- Computer History：依据已安装的 Computer History 技能说明，将其写成用户单独启用、授权后可用于定位原网页、文档或消息的可选线索来源。电脑活动时间不等于校园事件发生时间，摘要不是独立来源；不捆绑、不自动启用、不新增导入或监测接口。
- 本轮不查询 Computer History 状态、活动流或个人记忆，不改变观察设置，不处理任何真实聊天、图片或活动记录。
