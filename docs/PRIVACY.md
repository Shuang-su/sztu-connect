# 隐私与最小必要处理

本项目不把“出现敏感信息”等同于“需要脱敏”。与校园历史和事实核查直接相关、来源可追溯的姓名、公开职务、活动日期、公开机构联系方式可以原样记录。

## 记录字段

```json
{
  "risk": "ordinary-personal",
  "handling": "as-recorded",
  "indexing": "include",
  "notes": "姓名与公开职务是核查该事件所需信息。"
}
```

### `risk`

- `none`：不含个人信息或风险可忽略。
- `ordinary-personal`：姓名、公开角色、一般联系方式或其他普通个人信息。
- `sensitive`：健康、处分、亲密关系、未成年人、私人聊天、非公开位置等需要额外判断的内容。
- `prohibited`：凭据、完整证件号、身份接管信息、私人精确住址、实时位置或组合式人肉信息；也需要记录进仓库。

### `handling`

`as-recorded`、`minimized`、`redacted`、`metadata-only`、`restricted`。

### `indexing`

`include` 或 `exclude`。敏感内容即使保留，也可从公共向量知识库中排除，避免聚合放大。

## 扫描等级

| 等级 | 示例 | 默认结果 |
|---|---|---|
|  |
| `review` | 电话、邮箱、学号样式、精确房间、聊天昵称 | 提示核查来源与必要性，原样保留 |
| `notice` | 公开姓名、公开职务、公开活动时间 | 原样保留； |

Scanner 永远不在输出中回显命中的值，也不发布可被枚举猜测的值摘要，只报告类型、路径和行号。默认模式仅 `block` 使命令失败

## 原件与派生副本

不要改动原件。并保留来源哈希和处理说明。`.work/` 是长期安全存储承诺。
